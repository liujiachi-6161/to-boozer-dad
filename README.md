# 体育助教系统
项目名称：To Boozer Dad’s Sports Work
功能清单
1.日历月视图，标记有课程日期
2.点名签到，学生状态：到/缺勤，支持随机点名
3.随堂手记，AI教案存档、删除
4.AI双模型切换：DeepSeek低成本构思小游戏；豆包用于教案撰写、互动
5.学期课时统计、各班出勤率汇总
6.Vercel‑KV云端同步，手机电脑多设备互通

##部署步骤
1.本地全部文件准备完成
2.git推送至GitLab仓库
3.Vercel导入仓库
4.创建Vercel KV数据库并绑定项目
5.在Vercel环境变量填入：
DOUBAO_KEY
DOUBAO_ENDPOINT
DEEPSEEK_KEY
6.部署完成，绑定自有域名

##使用说明
1.课堂档案标签页：日历选择日期，填写班级、课时，粘贴载入学生名单，点名，写随堂笔记，保存AI教案
2.AI助教标签页：选择模型，提问，可将AI回答保存至当日记录
3.数据统计标签页：查看全部课时、出勤汇总
4.云端同步按钮：手动同步本地和云端数据
